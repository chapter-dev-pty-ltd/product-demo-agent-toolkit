# Library

What a cut is made of. The CLI picks these by name (`--look silk`), so an agent never reads this folder directly.

- `looks/`: a Look is the whole style a demo is cut in: backdrop, frame, fonts, headline, sound.
- `backdrops/`: what sits behind the product.
- `cursors/`: the pointers the cut paints, matched to the cursor the app asks for.
- `sounds/`: clicks, keys, whooshes and music beds.
