# Library

What a cut is made of.

- `backdrops/`: what sits behind the product. Picked by `backdrop` in `.product-demo/config.json`.
- `cursors/`: the cursor the cut draws along the pointer's path, in the colour `cursor` picks.
- `sounds/`: the sounds the cut plays, all CC0 from Freesound. A click picked at random for each click: `click-1.wav` is [mouse click](https://freesound.org/people/Weak_Hero/sounds/790532) by Weak_Hero, `click-2.wav` [mouse_click.wav](https://freesound.org/people/Six%20Ways/sounds/223445) by Six Ways. The keys, `key-1.wav` to `key-8.wav`, `space.wav` and `enter.wav`, are keystrokes cut from one recording of one keyboard: [Computer keyboard typing close up](https://freesound.org/people/khenshom/sounds/565204) by khenshom.
