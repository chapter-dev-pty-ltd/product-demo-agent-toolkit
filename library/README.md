# Library

What a cut is made of.

- `backdrops/`: what sits behind the product. Picked by `backdrop` in `.product-demo/config.json`.
- `cursors/`: the cursor the cut draws along the pointer's path, in the colour `cursor` picks.
- `sounds/`: the clicks the cut plays in turn, one per click, both CC0 from Freesound: `click-1.wav` is [mouse click](https://freesound.org/people/Weak_Hero/sounds/790532) by Weak_Hero, `click-2.wav` is [mouse_click.wav](https://freesound.org/people/Six%20Ways/sounds/223445) by Six Ways.
