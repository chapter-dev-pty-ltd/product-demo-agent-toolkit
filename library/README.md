# Library

What a cut is made of.

- `backdrops/`: what sits behind the product. Picked by `backdrop` in `.product-demo/config.json`.
- `cursors/`: the cursor the cut draws along the pointer's path, in the colour `cursor` picks.
- `sounds/`: the sounds the cut plays, all CC0 from Freesound. A click picked at random for each click: `click-1.wav` is [mouse click](https://freesound.org/people/Weak_Hero/sounds/790532) by Weak_Hero, `click-2.wav` [mouse_click.wav](https://freesound.org/people/Six%20Ways/sounds/223445) by Six Ways. A key for each key typed: `key.wav` is [mechanical key medium](https://freesound.org/people/bigmonmulgrew/sounds/378084) by bigmonmulgrew, `space.wav` [MECH-KEYBOARD-01](https://freesound.org/people/newagesoup/sounds/348239) by newagesoup, `enter.wav` [enter key](https://freesound.org/people/uEffects/sounds/180997) by uEffects.
